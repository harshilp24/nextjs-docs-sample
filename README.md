# Relay Docs (sample)

A custom documentation site built with Next.js (App Router, static export) and deployed to GitHub Pages.

- 4 guides + 2 reference pages, defined in `content/docs.ts`
- Sidebar with search filter, on-this-page TOC, prev/next, copyable code blocks, dark mode

```bash
npm install
npm run dev
```

Pushing to `main` deploys via `.github/workflows/deploy.yml`.
